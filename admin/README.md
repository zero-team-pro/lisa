# Lisa Admin Panel

## Available Scripts

In the project directory, you can run:

### `yarn start`

Runs the app in the development mode.\
Open <http://localhost:3000>. The port is set in `vite.config.mts`.
Set `VITE_APP_API_HOST` (HTTP) or `VITE_APP_API_HOST_LE` (HTTPS) for the
development gateway; Vite proxies `/api` to that host.

The page will reload if you make edits.\
You will also see any lint errors in the console.

### `yarn test`

Launches the test runner.

### `yarn build`

Builds the app for production to the `dist` folder.
